# Agent instructions

This repository is spec-driven. Before changing code, tests, dependencies, or build/runtime configuration, read and follow `CLAUDE.md`, `openspec/config.yaml`, and the applicable current-state specs under `openspec/specs/`.

No implementation may begin without a strictly valid, human-approved OpenSpec change containing the required proposal, delta specs, design, and tasks. Do not edit current-state requirement content directly; archive validated deltas into it.
